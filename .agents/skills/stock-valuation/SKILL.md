# 个股估值分析（Stock Valuation）

对**单只股票**做估值判断的方法。核心信念：**估值口径必须匹配生意属性**——拿制造业的 PE 套地产、拿静态 PE 套周期股，都会给出方向性错误。

## 何时触发
- 用户问「东山精密怎么估值」「滨江集团值多少」「XX 股现在贵不贵/便宜吗/目标价多少」「帮我分析/估值某一只股票」。
- 投顾/选股场景需要对单个标的给出「贵/便宜 + 安全边际 + 何时重估」的结论。
- 与 `prosperity-analysis` 区分：那是**行业级**配置方向；本技能是**个股级**估值落地。

## 总流程
**取实时估值字段 → 识别生意属性 → 选估值口径 → 交叉收敛 → 给方向性结论 + 关键节点**。整套核心是两步「分类」，其余是执行。

### 第 1 步：取实时估值字段（数据获取）
- **首选 tushare MCP**：在会话内直接调 `mcp__tushareMcp__daily_basic`(PB/PE两口径/市值/股息率/换手)、`mcp__tushareMcp__daily`(现价/昨收/涨跌幅)、`mcp__tushareMcp__stock_basic`(名称/行业)、`mcp__tushareMcp__fina_indicator`(营收与净利同比/毛利率/ROE)。字段映射、`ts_code` 后缀规则、口径局限(无前瞻PE、港股缺估值字段)见 `references/data-source.md`。
- **tushare 不可用/失败时**：退回 `scripts/fetch_snapshot.py <代码>` 拉取最新价、PB、PE 三口径(静态/TTM/动态)、总市值/流通市值、营收与净利同比、换手率、涨跌幅（腾讯/东财双源）。
- 脚本用 `curl` 直连（Git Bash 下 curl **不读 Windows 系统代理**，能绕过本机被墙/损坏的代理）腾讯 `qt.gtimg.cn` 与东财 `push2.eastmoney.com` 公开接口，双源交叉核对。
- **若 akshare/CLI 报 `ProxyError` 回退到 `LocalProvider` 示例数据，不要用示例数据凑数**——改用本脚本或 curl 直连（详见 `references/data-source.md`）。
- 数据务必标注**时点**（接口返回 `YYYYMMDDHHMMSS`）。东财偶发「接收失败」，重试或退回腾讯源即可。

### 第 2 步：识别生意属性 → 选估值锚
| 生意属性 | 典型示例 | 主口径 | 辅口径 | 别碰 |
|---|---|---|---|---|
| 景气成长/制造 | 东山精密(PCB)、半导体、新能源 | 前瞻PE + PEG + 周期中枢盈利 + 逆向DCF隐含增长 + 估值历史分位 | EV/EBITDA、PS | 孤立静态PE、PB |
| 地产/金融 | 滨江集团、银行、保险 | **PB + RNAV重估净资产 + 股息率** | 重估后PB折溢价 | PE(结算滞后失真) |
| 周期资源 | 资源/大宗商品 | 周期中枢盈利(类似CAPE) + EV/EBITDA | 价格/库存拐点 | 静态低PE当作便宜 |
| 稳定价值/消费 | 白酒、家电、公用 | DCF + 股息率 + 稳态PE中枢 | 自由现金流 | 短期增速PE |

> 关键判断：**这家公司的盈利是「滞后确认」还是「前瞻定价」？重资产/地产/金融的利润被会计节奏与减值严重扭曲，PE 天然失真，必须回到 PB/RNAV/现金流；高景气成长股股价里已price in 未来增长，必须用前瞻估值 + 隐含增长看预期有多满。**

### 两个横切维度（叠加在生意属性之上）
选完口径还不够，还要用两个横切维度校准「该给溢价还是折价」：

**① 质量溢价（Quality Premium）——决定「同样的利润值几倍」**
- 含义：同样一块钱利润，**质量更高**的公司市场愿意给更高倍数。质量 = **ROE 的水平与稳定性 × 毛利率 × 现金流转化率（净利→FCF）**，外加护城河/定价权/低杠杆/盈利低波动。
- 举例：茅台 PE 常年 25–30 倍 vs 普通制造 10–15 倍，同 EPS 下差距就是质量溢价——高质量盈利可持续、可再投资、折现率更低。
- 实操：**不能用行业平均 PE 套高质量龙头**（否则永远觉得贵）；反过来低 ROE、高波动、现金流转化差的公司要给**质量折价**。
- 本地量化抓手：ROE 是否常年 20%+、净利有多少变成自由现金流、毛利率稳定性。字段见 `references/data-source.md` 的营收/净利/毛利率项（**该源财务字段需逻辑自检，勿盲信**）。

**② 行业 β（beta）——决定「这只票的命运多大程度由行业/大盘决定」**
- 含义：β 衡量个股对**系统性波动**的敏感度，β>1 比大盘波动更大。高β = 强周期、顺周期、政策敏感（地产、券商、资源），股价由**行业β**主导而非个股α；低β = 稳定价值（水电、消费、公用）。
- 实操：高β行业里，单只个股的涨跌很大一部分是大盘/行业在动，**不能孤立看个股**，要先判断行业周期位置（衔接 `prosperity-analysis`）。
- 特殊警示：地产股 PB<1 往往是对「地产β下行」（房价、销售、信用风险）的**系统性定价**，不是个股错杀——所以必须用 PB+RNAV 把「行业β带来的系统性折价」和「个股真实净资产」拆开再看折溢价，避免把全行业打七折当成单股捡漏。

### 第 3 步：各口径落地
- **前瞻/动态 PE**：用未来12个月预测盈利做分母（当前动态PE 已隐含市场对下一年盈利的预期，看方差别只看均值）。
- **PEG**：PE / 盈利增速，≈1 内合理；增速能否维持是核心。
- **周期中枢盈利**：取一轮完整周期的中枢净利(而非顶点/谷底年) × 合理倍数，得到不追情绪的价值区间。
- **逆向 DCF（隐含增长率）**：反推当前股价隐含的未来复合增速，判断泡沫/空间——景气股最重要的"温度计"。
- **相对估值分位**：当前 PB/PE 落在自身历史的分位；**高处叠加景气见顶=高危，低位但基本面恶化=价值陷阱**。
- **PB + RNAV**：地产/金融把账面土储/资产按市价重估，算相对真实净资产的折溢价；优质资产「PB 贴着面值」可能仍相对真实价值有折价。
- **股息率**：高分红标的的价值底，需核实当期分红口径。

### 第 4 步：收敛 → 方向性结论
不要给「PE 多少倍=合理」的静态答案，而是给：
1. **贵/便宜方向**：当前估值落在自身历史分位哪里、隐含了多少预期、安全边际厚不厚。
2. **胜负手在哪**：估值能否兑现由什么驱动（预期上修/下修的"二阶导"）。
3. **关键节点**（决定何时能重估，按生意属性不同）：
   - 景气成长/制造 → **等财报（中报/年报）验证盈利兑现**，看单季营收增速、净利率修复、扣非、毛利率稳定性。
   - 地产/金融 → **等销售月报 + 土储/资产重估**（不是利润表！）。
   - 周期资源 → **等商品价格/库存/产能利用率的拐点**。
   - 稳定价值 → **等经营现金流 + 分红能否持续**。

> 结论为「贵/高估/等买点」但标的值得持续跟踪时：建议用 `watchlist-manager` 技能加入观察仓
> （`manage_watchlist.py add <code> --note <等什么/目标价> --source stock-valuation`），
> 后续由 w-bottom-screener / momentum-rotation 等对观察池做信号筛选。

## 输出格式（结构化，供研报/后续选股用）
```
标的: <代码/名称>  <数据时点>
实时快照: 现价 / PB / PE(静/TTM/动) / 总市值 / 股息率 / 营收与净利同比
生意属性: 景气成长制造 | 地产金融 | 周期资源 | 稳定价值（选型依据一句话）
估值口径: 前瞻PE+PEG / 周期中枢 / 逆向DCF隐含增长 / 估值分位 / RNAV折溢价（给数值/区间）
方向结论: 贵 | 合理 | 便宜（附安全边际厚薄）
胜负手: 预期上修/下修 或 资产重估 或 价格拐点 或 现金流分红
关键节点: 等财报验证兑现 | 等销售月报+土储重估 | 等价格库存拐点
风险: 预期透支回撤 | 价值陷阱 | 景气与股价脱钩 | 重估下修
```

## 常见陷阱自检（输出前逐一过）
- [ ] 是否拿 PE 套了地产/金融（利润结算滞后，PE 失真）？
- [ ] 是否在周期股盈利顶点看到低 PE 就当便宜买入（低 PE 纯属顶点）？
- [ ] 是否在景气最高、预期最满处追高（PB/PE 落在历史极端高分位）？
- [ ] 景气好但股价已不涨——是否检查预期透支/拥挤度过高（脱钩）？
- [ ] 是否用扣非/现金流/毛利率稳定性识别伪景气（一次性收益冲高）？
- [ ] 关键节点是否还给错对象（地产等中报、制造等销售月报，都是错的节奏）？
- [ ] 是否拿行业平均 PE 套了高质量龙头（忽视质量溢价，永远觉得贵）？
- [ ] 是否把高β行业的系统性下跌当成个股错杀（地产低 PB 是行业β定价，不是单股捡漏）？

## 估值方法全谱系（备查）
第 2/3 步的四套「生意属性→口径」只是相对估值里的四个支线，不是全集。遇到不熟悉的标的后台参照全谱系再重新选口径：
- **绝对估值**：DCF 现金流折现（现金流稳定可预测：白酒/水电/公用/消费龙头）；DDM 股息折现（高分红低增长：银行/高速/电信）。
- **相对估值**：PE 四口径(静态/TTM/动态/前瞻)、PEG、PB(金融/地产/周期底部)、PS(早期亏损高成长)、EV/EBITDA(重资产/高负债)、PCF(现金流而非账面利润)、SOTP 分部加总(多元化控股)。
- **特定资产/生意专用**：RNAV/NAV 重估净资产(地产/控股)、储量估值 EV/资源量(矿业/油气)、单用户估值 EV/DAU(互联网平台)、重置成本/清算价值(极端情形)。
- **反向/温度计**：逆向 DCF 隐含增长率(泡沫温度计)、估值历史分位、CAPE/周期中枢盈利(平滑周期股)。
- 唯一不变的原则：**先识别生意属性(第2步)，再用质量溢价与β两个维度校准(横切)，最后选口径——顺序不能反。**
