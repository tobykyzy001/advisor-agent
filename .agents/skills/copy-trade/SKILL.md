# 抄作业分析（Copy Trade）

把**一个选股信号源**（群主/UP主/大V每天发的"作业"消息流）当作研究对象，回答三件事：

1. **他说了什么**——把消息流解析成结构化的「信号事件」时间线。
2. **他做得怎么样**——把路线送去轻量回测，看胜率/收益/换手。
3. **现在值不值得抄**——对期末持仓的每个标的做估值/景气判断，给「跟/不跟/怎么跟」的结论。

> 核心信念：**抄作业的风险不在"跟不跟得上"，而在"你抄的是一笔有逻辑的持仓，还是一条没头没尾的喊单"**。本技能先把它还原成可验证的路径，再谈值不值得跟。

## 何时触发
- 用户发来 `http://.../dingall?a=xxx` 之类的群作业链接，说"分析下最近的作业""是否值得抄""回测下他的持仓路线"。
- 用户贴一段"某人每天发买卖方向"的消息流，要求评估这个信号源可不可信。
- 与 `stock-valuation`（单只个股估值）、`portfolio-tracker`（自己的持仓）、`prosperity-analysis`（行业景气）区分：本技能是**对一个外部信号源做清洗→还原→回测→可信度评估**。

## 数据源约定

- **作业内容**：来自用户给的链接，用脚本直连抓取（`scripts/fetch_homework.py`）。抓不到时提示用户提供原文/离线 HTML。
- **行情/估值**：回测用 tushare MCP 的 `mcp__tushareMcp__daily`（历史日K，无频率限制）；"是否值得抄"的估值快照优先 `mcp__tushareMcp__daily_basic`（**注意：5 次/天限额、`rt_k` 实时接口无权限**），超限或失败就退化为"日K技术面 + 定性逻辑"，不硬凑。
- **时点必须标注**：所有行情/估值字段标接口返回的时点。

## 关键局限（必须先认清，否则回测会误导）

1. **信号是模糊的**：群主常用黑话/题材/隐含语表达（"锁仓""低吃""择机走人""做T""冷液""燕子家族"），很少给精确价格与仓位。所以：
   - 买入/卖出**时点**只能近似（信号消息当天/次日）。
   - **仓位**只能假设（等权、满仓/空仓二值）。
   - 回测结论是**方向性还原**，不是可复现的精确业绩，**必须显式标注"近似/假设化"**。
2. **标的映射依赖人工确认**：黑话→具体股票的映射（见 `references/alias-map.md`），脚本会**自动从上下文推断候选**，但必须**列出让用户确认后**才固化；未确认的标注"待确认"，不进入回测。
3. **涨跌停/停牌/换手偏差**：回测按"信号次日开盘价成交"近似，涨停买不进、跌停卖不出的情形不建模，属可接受的近似（在输出里说明）。

## 总流程

```
抓取链接 → 解析成消息(时间戳/发言人/正文) → 抽取信号事件(买卖/持仓/清仓)
   → 别名→标的映射(自动推断+人工确认) → 轻量回测(还原路线收益/胜率)
   → 期末持仓逐个估值 → 综合结论(值不值得抄 + 怎么抄 + 风险)
```

### 第 1 步：抓取 + 解析

```bash
python .agents/skills/copy-trade/scripts/fetch_homework.py "<链接>"
```

- 直连（urllib 关系统代理，见 stock-valuation 的 data-source.md 同款原因），把 HTML 存到 `output/copy-trade/<作者>_<日期>.html`（已 gitignore），并原样打印解析后的结构化消息。
- 结构化字段：`时间戳` / `发言人` / `是否群主` / `正文` / `是否撤回`。清洗掉图片、HTML 标签、"[撤回]"、"回复@xxx"噪音。

### 第 2 步：抽取信号事件（路线还原）

从正文中用**动作词 + 标的词**抽取事件，动作词映射为方向：

| 动作词 | 方向 |
|---|---|
| 低吃 / 低吸 / 买入 / 新开 / 建 / 锁仓 / 满仓 / 回 / 拿先手 / 给半仓 / 猛干 | **买入/持有** |
| 止盈 / 砸 / 割 / 走 / 兑现 / 出 / 空仓 / 清仓 / 拉黑 / 移出 | **卖出/清仓** |
| 锁仓 / 没动 / 让子弹飞 / 观察 / 不主观 | **持有/观望** |

每个事件落在时间线上，形成 `事件流`。这是"还原路线"的最小单元。

### 第 3 步：别名 → 标的映射（本技能的重头）

群主把标的叫成"冷液、硅微粉、燕子家族群、折叠、铜箔、电源、特高压、靶料/靶材之..."。映射表在 `references/alias-map.md`：

```yaml
# 已固化并确认的映射（可编辑）
别名:  { 题材: "硅微粉", 候选tss: ["688300.SH"], 标的: "联瑞新材", 备注: "PTFE方案硅微粉填料龙头" }
```

- 脚本 `symbol_map.py` 做**自动推断**：扫描消息里出现的"A股二字/三字/四字中文名称 + 罕见词"，用 `mcp__tushareMcp__stock_basic` 按名称反查 ts_code；对纯黑话/题材，先落到候选（如"冷液→申菱环境 301018.SZ"），**输出候选清单让用户确认**，确认后写入 alias-map（不回写仓库，写 `output/copy-trade/alias-map.override.yaml` 优先加载）。
- **未确认的别名不进入回测**，只在结论里标注"待确认，未纳入收益统计"。

### 第 4 步：轻量回测

```bash
python .agents/skills/copy-trade/scripts/backtest.py --period 2026-08-14..2026-08-31
```

- 用 `mcp__tushareMcp__daily` 拉每个已确认标的在时间窗内的日K。
- 回测假设（明示）：**信号出现当日用次日开盘价成交；买入=全仓/等权，卖出=清零；以收盘价逐日盯市**。等权回测源与组合两条线：信号源、逐日收益曲线、期末值、胜率、最大回撤。
- 输出 `output/copy-trade/backtest_<作者>.md` 路线还原表（一目了然）。

### 第 5 步：期末"是否值得抄"结论

对期末仍持有的标的，逐个用 `stock-valuation` 的方法（生意属性→ 口径→方向）判断 + 用 `prosperity-analysis` 看所属行业景气位置，收敛出：

- **值不值得抄**：期末标的本身估值贵不贵、还在不在风口中、有没有安全边际。
- **信源本身可信度**：从回测的换手/胜率看它是"赚逻辑"还是"赚情绪"，给出"真跟单会怎样"（考虑跟单滞后/追高成本）。
- **怎么抄**：若跟，建议用（分仓 / 只在有明确逻辑点时跟 / 设纪律）；若 signal 源本身退潮（频繁换手+回撤），建议"只看不抄"。

## 与其它技能的分工

- 单只标的"贵不贵/怎么估" → `stock-valuation`（本技能第 5 步复用它的口径）。
- 行业景气上/下行、顺/逆周期 → `prosperity-analysis`。
- 自己持仓的持续复核 → `portfolio-tracker`（本技能输出的是"别人作业"，不代表你的持仓）。
- 挖到值得盯但其价位未到的标的 → `watchlist-manager`（加入观察仓持续跟踪：`manage_watchlist.py add <code> --source copy-trade`）。
- 知识资产/景气快照的周期更新 → `daily-update`。

## 生成数据 vs 技能方法（提交边界，重要）

- **提交**：本技能（SKILL.md + references/ + scripts/）与方法论、以及 `references/alias-map.md` 里**已确认且不含个人交易信息**的别名映射（可视为公开的题材→标的常识）。
- **不提交**：`output/copy-trade/` 下所有运行时产物——抓取的原始 HTML、解析出的消息流、回测结果、以及你现场确认并回写的 `alias-map.override.yaml`（含你个人的关注清单/界定）。这些是易过期动态数据/含个人关注信息，已被 `.gitignore` 忽略。

## 免责

本技能对第三方作业进行整理与近似回测，输出仅供研究参考，不构成投资建议；作业源信息可能带诱导/不确定性，行情数据有滞后，须标注时点与数据来源。
