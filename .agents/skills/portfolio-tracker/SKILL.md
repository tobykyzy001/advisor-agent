# 持仓清单管理（Portfolio Tracker）

用**一份结构化清单**保存持仓，并按每条持仓自己的**复核周期**定期重估，更新其**投资类型(投机/投资)、估值方式、估值价格、现价、结论**等字段。与 `stock-valuation`（单只个股的一次性估值）和 `prosperity-analysis`（行业级）互补：本技能是**持仓级别的持续跟踪**。

## 何时触发
- 用户说「帮我记下这笔持仓」「我持有 XX」「更新我的持仓」「看看我持仓里哪些该复核了」「XX 现在算投机还是投资」「持仓里谁贵了谁便宜了」。
- 定时自动化（Cron）触发本技能做周期复核。

## 核心概念

### 投资类型：投机 vs 投资
这是本技能最关键的标签，决定**该用什么纪律持有**：

| 类型 | 赚的是什么钱 | 持有逻辑 | 复核重点 |
|---|---|---|---|
| **投资** | 内在价值回归 / 现金流分红 | 便宜买、等价值兑现，看估值安全边际 | 估值是否仍成立、基本面是否恶化 |
| **投机** | 价格动量 / 预期差 / 情绪价差 | 追趋势、止盈止损、看边际变化 | 动量/情绪/资金是否还在，纪律(止损) |

> **关键规则**：投资类型会随「现价 vs 估值价格」动态变化——**当现价远超估值价格（预期透支、脱锚）且无基本面估值支撑时，这笔持仓的实际性质已经从"投资"滑向"投机"**，应把类型改标为 `投机` 并切换到投机纪律（设止盈/止损、不再拿估值当持有理由）；反之现价回落到安全边际内、逻辑重新由价值主导时，改回 `投资`。类型标签不是建档时一次写死的，而是每次复核都判一遍。

### 估值方式 / 估值价格
- **估值方式**：复用 `stock-valuation` 的「生意属性 → 估值口径」——景气成长用前瞻PE+PEG、地产金融用 PB+RNAV、周期资源用周期中枢+EV/EBITDA、稳定价值用 DCF+股息率。字段里写**口径 + 关键假设一句话**。
- **估值价格**：该口径收敛出的合理估值/目标价，可给单值也可给区间（如 `9.5~11`）。

### 复核周期 cadence
每条持仓自己登记 `cadence`（新增默认 `monthly`）。建议：`投机` 类用 `weekly/monthly`（要跟情绪/趋势），`投资` 类用 `monthly/quarterly`（跟财报/价值）。

```
.agents/skills/portfolio-tracker/
├── SKILL.md                      # 本技能（方法论，随仓库提交）
├── references/
│   └── holdings-template.yaml    # 持仓字段模板（已提交，holdings 为空）
└── scripts/
    └── manage_holdings.py        # 增删改查 + 周期比对 + 回写
output/portfolio/                 # 运行时持仓数据（已被 .gitignore 忽略，不入库）
```

> `references/holdings-template.yaml` 是**可提交的字段模板**（holdings 为空，不含真实持仓）；`output/portfolio/holdings.yaml` 是**运行时真实持仓**，含个人信息，故不提交。

## 工作流

### 1. 新增一条持仓
```
python .agents/skills/portfolio-tracker/scripts/manage_holdings.py add 600519 --name 贵州茅台 --type 投资 --cadence quarterly
```
一次性补齐各类字段（`--init key=值` 可重复）：
```
python ... add 600519 --name 贵州茅台 --type 投资 \
  --init 估值方式=DCF+股息率 --init 估值价格=1500 --init 建仓价=1380 --init 数量=100
```

### 2. 查看持仓与到期状态
```bash
python .agents/skills/portfolio-tracker/scripts/manage_holdings.py
```
输出每行显示投资类型、现价 vs 估值价格、以及 `DUE(该复核了) / ok 周期内`。

### 3. 到期复核（核心）
对每条 `DUE` 的持仓执行：
1. **取现价**：优先用 tushare MCP（`mcp__tushareMcp__daily_basic` 取 PB/PE/市值/股息率、`mcp__tushareMcp__daily` 取现价/涨跌幅，字段映射见 stock-valuation 的 `references/data-source.md`）；tushare 不可用时退回 stock-valuation 的 `scripts/fetch_snapshot.py <code>`。
2. **重估**：按该持仓已登记的 `估值方式`（或现场重判生意属性后更新口径），刷新 `估值价格`、`结论`（低估/合理/高估+一句话）。
3. **重判投资类型**：比较现价 vs 估值价格，套上面「投资类型动态变化」规则，更新 `投资类型`。
4. **回写**：
   ```bash
   python ... set 600519 现价=1450.5 估值价格=1500 结论=合理 投资类型=投资
   python ... mark 600519     # 回写 last_update，务必在更新完成后执行
   ```
   > 可选用 `--now YYYY-MM-DD` 指定"当前时间"测试/演示。

### 4. 增删持仓
```bash
python ... set 600519 备注=等中报验证现金流再上修   # 改某字段
python ... rm 600519                                # 删除持仓
```

## 输出格式（复核后可直接复用）
```
代码/名称: 600519 贵州茅台
投资类型: 投资 | 投机（为什么改/不变一句话）
估值方式: DCF + 股息率
估值价格: 1500（区间 1400~1600）
现价: 1450.5  结论: 低估，安全边际约 3%
下次复核: 下学期(YYYY-Qn)
风险/备注: ...
```

## 字段一览（每条持仓）
`code`(代码) / `name`(名称) / `投资类型`(投机|投资) / `估值方式` / `估值价格` / `现价` / `结论` / `更新时点` / `cadence`(复核周期) / `last_update`(运行时写，勿手填) / `建仓价` / `数量` / `备注`。详见模板注释。

## 与其它技能的分工
- 一次性给某只个股定估值口径/贵不贵 → `stock-valuation`。
- 判断该个股所属行业景气上/下行、顺/逆周期 → `prosperity-analysis`。
- 定期全量刷新知识库/景气快照的周期管理 → `daily-update`。

## 免责
本技能保存个人仓位并作研究性复核，输出仅供研究参考，不构成投资建议；行情/财务数据有滞后与波动，须标注时点与来源。
