# 飞神交易规则卡

本文件把《飞神语录.docx》中反复出现的交易观点整理为可应用的规则。它是风格规则库，不是历史回测结果。规则需要按“市场环境 → 板块阶段 → 个股角色 → 触发器”顺序使用。

## 规则优先级

1. 市场环境是总闸门；弱势环境下，个股信号默认降级。
2. 板块阶段决定个股信号的有效性；高潮和龙头转弱会压低后排评级。
3. 个股趋势和量价结构决定时点。
4. 交易周期决定持有耐心；超短、阶段题材和趋势核心不能混用。
5. 成本和仓位影响执行，但不能替代方向、趋势和失效条件。

## 收益来源模型

这套体系可以用下面的非数学化模型理解：

```text
产业趋势 × 预期差 × 核心公司 × 低成本筹码 × 交易纪律
```

它不是打分公式，也不能用来跳过证据检查。任一项明显缺失，都应降低动作强度。

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| MODEL-001 | 正确方向不等于正确交易，收益还取决于预期差、核心地位、成本和纪律 | 分别检查方向、时点、角色和执行 | 不要只因为产业趋势正确就给出参与结论 |
| MODEL-002 | 大逻辑的兑现可能跨越多个上涨和回调周期 | 区分方向判断和阶段交易 | 不把长期逻辑误写成固定的2–3年收益承诺 |
| MODEL-003 | 长期空间必须带兑现期限和中间验证节点 | 明确“发生什么、何时发生、如何确认、何时重估” | 没有时间限制的目标市值或终局叙事不属于可执行预测 |
| MODEL-004 | 战略预期与战术仓位是两层决策 | 预期不变时可保留战略仓，阻力和高位阶段用战术仓游击 | “逻辑未变”不能推导出仓位永远不动 |

## 市场环境规则

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| MKT-001 | A股交易要同时看政策、产业趋势和流动性 | 先判定市场是否允许进攻 | 单一政策消息不足以确认环境 |
| MKT-002 | 弱势环境下不要做突破 | 降低仓位，等待或只小仓试错 | 市场重新改善后再恢复进攻 |
| MKT-003 | 大盘调整时优先抗跌而非逆势股 | 选择承接稳定的方向 | 逆势股可能只是暂时吸引眼球 |
| MKT-004 | 个股表现依附于大盘环境 | 个股分析必须带市场背景 | 不要用少数强股证明市场普遍可做 |
| MKT-005 | 赚钱效应、市场高度和主线龙头共同反映情绪 | 强环境提高容错，弱环境收缩 | 只看指数或只看涨停高度都不完整 |
| MKT-006 | 历史季节走势可用于建立大盘预期 | 用历史表现做背景，不作单独买卖信号 | 历史统计不保证当期重复 |
| MKT-007 | 牛市尾声或高位震荡是独立战术状态，不等同于立即清仓或新一轮普涨 | 聚焦主线核心，震荡低吸、拉升兑现，逐步降低容错 | 不做辅线和无周期依据的超跌反弹，不因盘面仍热闹就否认尾声风险 |
| MKT-008 | 行情后半程通常越来越难并向少数核心聚焦 | 收缩无差别分散，跟踪资金从旧热点向新热点的迁移 | 单日轮动不能证明新主线形成 |

## 产业和板块规则

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| SEC-001 | 资金会向政策、产业趋势和巨头投入方向聚集 | 优先研究产业链，而不是只追新闻 | 巨头投入不等于每只股票受益 |
| SEC-002 | 板块常沿历史路径从主线到细分、扩散和轮动 | 研究相似主题的炒作路径，寻找未充分定价分支 | 历史路径只是先验，不是机械复制 |
| SEC-003 | 大容量板块更适合多类资金腾挪和长周期扩散 | 可在多个细分方向平铺，再按节奏切换 | 小容量题材可能适合短炒，但持续性较弱 |
| SEC-004 | 大板块健康行情通常有龙头、中军和先锋 | 优先核心股和扩展方向 | 只有后排补涨时要降级 |
| SEC-005 | 龙头或一线强势股下跌时，后排不一定安全 | 先检查龙头和中军是否稳住 | 不能把低位当作安全的充分条件 |
| SEC-006 | 板块高潮时追入，容易成为阶段性接盘者 | 观察震荡板块的先手或等待分歧 | 高潮后可能继续上涨，但盈亏比恶化 |
| SEC-007 | 外部利好造成的高开在弱势环境中容易高开低走 | 不把高开直接当强势确认 | 自发形成的行情更值得跟踪 |
| SEC-008 | 核心股通常同时具备龙头或关键产业位置、较大市场容量、持续叙事和资金可持续性 | 在板块内部优先筛选核心，而不是只看涨幅或低价 | “有故事”不能单独证明核心地位 |
| SEC-009 | 市场认知通常从未知、知道、认可、全民讨论逐步扩散，后段接力风险上升 | 在广泛共识前寻找预期差，高潮阶段降低追涨意愿 | 低认知不等于低风险，仍需产业和价格证据 |

### 认知扩散与板块阶段动作

| 阶段 | 默认动作 | 需要的确认 | 主要失效 |
|---|---|---|---|
| 无人认知 / 题材种子 | 建立候选观察，必要时小仓分层预埋 | 政策、产业变化、订单/技术/供需等真实变量，且能映射核心公司 | 只有概念故事、没有产业兑现路径或市场完全无承接 |
| 少数人发现 / 开始被知道 | 核心观察，筛龙头、中军、先锋 | 首批异动、成交放大、核心股主动走强并有板块跟随 | 单日异动后无扩散、无换手承接或跌回启动位 |
| 题材命名 / 被认可 | 分层参与，优先核心，不追杂毛 | 板块联动、龙头脱离个股逻辑、中军放量、细分开始轮动 | 题材有名称但无联动，龙头断板后无人接力 |
| 主升扩散 | 持有核心，新开仓只做分歧确认 | 龙头和中军继续扩展空间，板块梯队完整，市场环境配合 | 龙头高位放量滞涨、涨停数量下降、补涨亏钱效应扩大 |
| 广泛讨论 / 全民共识 | 持有者看趋势和成本，新买者降低追涨意愿 | 热度普及、逻辑被广泛复述，但核心仍能健康分歧修复 | 一线不再开拓、后排乱涨、高位放量不涨、利好兑现不涨 |
| 高潮 / 退潮 / 重建 | 减仓或回避，等待核心重建结构 | 龙头是否企稳、趋势是否未破、新分支是否接棒 | 用长期故事掩盖结构破坏，或把反抽误当二波确认 |

## 个股角色和持有规则

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| STK-001 | 趋势核心股、阶段题材股、超短股的持有方法不同 | 先分类，再决定耐心和仓位 | 不要把短线票套成长期投资 |
| STK-002 | 趋势型大牛股通常由政策和基本面推动，波动常是上车机会 | 趋势线未有效破坏时，回撤可观察或分层参与 | 趋势线有效破坏后不能只靠故事硬扛 |
| STK-003 | 龙头位置高不等于低位后排更安全 | 调整到合理位置时优先核心 | 仍需市场和板块环境配合 |
| STK-004 | 业绩不是股价唯一因素，预期和博弈会先于业绩反映 | 用预期判断方向，用兑现判断阶段 | 预期不能替代价格和资金确认 |
| STK-005 | 逻辑未变但股价阶段性不涨，不必立即否定逻辑 | 区分正常调整与结构破坏 | 逻辑未变不代表必须继续持有 |
| STK-006 | 消息催化阶段没有可靠目标价，更多适合波段 | 控制持有周期，等待逻辑兑现 | 不要把催化阶段当成无限期趋势 |
| STK-007 | 调整要区分趋势中的良性回撤和高位资金撤退 | 检查趋势、成交量、承接和筹码后再决定低吸 | 不能把所有下跌都称为上车机会 |

## 入场和量价规则

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| ENT-001 | 最忌临时起意和随意追涨 | 先完成市场、板块和角色判断 | 看到上涨本身不是理由 |
| ENT-002 | 有效突破后趋势从震荡向下转为震荡向上 | 确认后再考虑加仓 | 突破前可能继续下跌 |
| ENT-003 | 冲出平台后又回到平台，通常属于弱势 | 暂时回避或减仓 | 需要重新形成有效突破才恢复关注 |
| ENT-004 | 双底后不再创新低才有参考价值 | 作为短线结构确认 | 仅有两次触底不等于反转 |
| ENT-005 | 仙人指路需要前期有适度涨幅、当日量超过前日、收涨约2%，且次日高走 | 条件齐全后才确认 | 单根上影线不能直接命名为仙人指路 |
| ENT-006 | 堆量上行节节高表现为上升途中的区间堆量、量峰逐步收敛并受13/34/55日线支撑 | 关注上升通道下轨或13日线附近 | 需要确认仍在上升通道 |
| ENT-007 | 空头承接覆盖出现在下跌末端，跌幅收窄且缩量阳线覆盖最后最大阴线实体 | 作为短线进场确认 | 必须先确认接近阶段低点 |
| ENT-008 | 扭转乾坤要求反弹阳线覆盖最后阴线实体，量约放大一倍以上 | 回踩反转阳线附近观察 | 反弹量价不匹配时降级 |
| ENT-009 | 颈线位量超表现为量超过前高最大量但价格尚未突破，随后缩量蓄势 | 观察颈线下的确认机会 | 放量不涨也可能是压力而非蓄势 |
| ENT-010 | 上方筹码压力有效时，放量但股价不涨 | 等待压力消化，不把放量当买点 | 需要结合位置和板块强弱 |
| ENT-011 | 低位预埋和突破确认是两种不同的入场路径 | 预埋用小仓分层，确认后允许加仓 | 不能用低成本逻辑替代突破确认，也不能因追求确认而否定所有先手 |
| ENT-012 | 确认需要反复，单日强势、抗跌或单一利好只是证据点 | 检查回落承接、再次主动走强、板块联动和基本面节点 | 今日抗跌可能只是明日补跌，不能一次观察就升级状态 |

## 持仓、做T和退出规则

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| HOLD-001 | 低成本是抵御大盘波动的重要方式 | 趋势核心可保留底仓并滚动操作 | 低成本不能取消退出规则 |
| HOLD-002 | 高 conviction 趋势股可用耐心换取更大波段 | 允许正常波动，不因一两天不涨换股 | 趋势或板块结构破坏时重新评估 |
| HOLD-003 | 做T应服务于降低成本和增加主动权 | 只在趋势或可识别通道内做T | 不能用T掩盖下降趋势 |
| HOLD-004 | 下降通道可反复做T，但最佳方案通常是先退出，等趋势扭转后再回 | 把T视为次优战术 | 趋势持续走弱时停止T |
| HOLD-005 | 做T的目标是降低成本和保持主动权，不是短线赌博 | 在可识别的上升趋势或通道内执行 | 下降趋势中优先考虑退出，不能用T掩盖判断错误 |
| HOLD-006 | “预期不变，战术游击”允许战略仓与战术仓采用不同动作 | 战略仓跟踪产业兑现，战术仓在阻力、新高和回撤空间之间分层交易 | 战术游击不能掩盖兑现延期或结构破坏 |
| EXIT-001 | 板块人人皆知、高潮加速时，主控资金可能转向兑现 | 减少追涨，考虑降级 | 高潮不是立即下跌的保证 |
| EXIT-002 | 龙头转弱、后排补涨加速而一线不再开拓，板块可能变盘 | 降低后排仓位和评价 | 只有当龙头重新稳住才恢复强判断 |
| EXIT-003 | 突破失败、跌回平台、有效跌破趋势线 | 减仓、回避或等待重建结构 | 不能靠叙事否认结构破坏 |
| EXIT-004 | 下降通道上轨可能是减仓位置 | 先出再等趋势扭转 | 需要识别真实通道而非主观画线 |
| EXIT-005 | 进攻带来收益，防守决定能否留下收益 | 保留现金和退出纪律 | 防守不是永久空仓 |
| EXIT-006 | 预期形成、资金进入、故事扩散后，预期兑现和全民一致可能成为卖出风险 | 观察共识扩散和资金兑现，高潮阶段不追 | 一致性风险不是立即下跌的确定性预测 |
| EXIT-007 | 狂欢途中可以主动分批退场，不必等待最终趋势破位 | 新高、目标区、加速或仓位过重时先兑现战术仓 | 预防性减仓不等于彻底否定长期逻辑 |
| EXIT-008 | 兑现期限持续后移本身就是重估信号 | 到期检查订单、产品、客户、业绩或市场确认节点 | 不能用更遥远的终局故事自动延长原计划 |

## 超短规则

| ID | 规则 | 应用动作 | 失效 / 注意 |
|---|---|---|---|
| ST-001 | 超短先看情绪周期和题材高度，再看指数 | 小仓位配合市场状态 | 不适合把超短交易直接复制给普通持仓 |
| ST-002 | 买在分歧、卖在一致 | 分歧时看承接，一致高潮时兑现 | 需要结合题材高度和市场容错 |
| ST-003 | 龙头连续放量分歧后不加速，并被新票卡位，原龙头更适合卖出 | 将机会转向首板或二板 | 市场高度受限时仍需小仓位 |

## 冲突处理

- 市场弱势优先于个股强势，先降级仓位和动作。
- 板块高潮或龙头转弱优先于个股低位，后排不能因低位自动升级。
- 趋势未破时，短期不涨不等于退出；结构破坏时，长期故事也不能自动保留。
- 做T属于执行工具，不是趋势判断工具。
- 当前价格和形态属于时点证据，不能替代产业方向和板块阶段。
- 证据不足时输出“候选观察/待验证”，不输出强结论。
