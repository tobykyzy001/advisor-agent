> 状态：动态仓位下两融等 4 个单指标过初筛；纯 BS 下仅 PE/换手率反转、北向/开户趋势通过，两融 BS 不成立
> 标记：✅ 已验证 / ⏳ 待验证 / ⛔ 不可得或不做
> 用途：沉淀「舆情择时」的已知事实与待验证项，作为后续完整报告的依据。
> 仅供研究参考，不构成投资建议。

## 一、研究问题与判定对象

- **问题**：以沪深300ETF（510300）为择时标的，情绪/舆情信号能否在「收益不显著变差」的前提下降低回撤、提高风险调整后收益？
- **主基准**：510300 复权净值（含分红）买入持有。
- **对照基准**：沪深300指数（000300）买入持有。两者差额用于解释 ETF 跟踪误差、费用与分红口径，不作为策略超额来源。
- **现金腿**：空仓期放 511880（银华日利）等货币 ETF；同时给「0 收益现金」的保守口径，避免货币基金收益美化结论。
- **执行口径**：T 日收盘生成信号，T+1 开盘或 T+1 收盘执行；禁止用 T 日收盘价成交。
- **样本区间**：510300 上市（2012-05，以实际数据校验为准）起；分段报告 2013–2015、2016–2018、2019–2021、2022–2026。

### 3.1 数据源结论：REST 还是 MCP

- **tushare REST 直连已验证可覆盖本研究的行情与情绪原料**，优先用它：可幂等落库、可复现、不额外占用上下文。
- **tushare MCP 端点确实是真 MCP**（258 个工具），但当前会话未挂载；挂载后 258 套工具 schema 会显著占用上下文，适合临时探索，不适合作为回补管道。
- **已落地**：`fetch_quotes.py` 支持按代码自动分流 `fund_daily`（ETF/LOF）/`index_daily`（指数）/`daily`（个股）/`hk_daily`（港股），指数须带完整后缀；510300/000300/511880 已完成落库。`fund_adj`/`fund_nav` 未接入 CLI，需要绝对复权价时再单独取。
- **安全**：MCP URL 内嵌 token，不写入仓库；token 已在对话中明文出现，建议尽快轮换。

**关键诊断**

- 2014 年过早降仓是最大拖累（28.1% vs 53.8%）；2015 年防守有效（16.0% vs 6.8%）。两轮牛熊下来基本抵消。
- 单指标分位没有稳定单调性：换手率 80–100 组未来 60 日平均收益 +4.06%，反而高于 60–80 组的 -1.19%；PE 最高组 +0.70%，也不是负收益。「高分位=见顶」不成立。

**结论**：按预注册标准，「水平分位 + 只降仓」这条路径无效。不调阈值、不换区间重试。

**下一轮假设（需重新预注册）**

1. **边际变化而非水平**：热度变化率、以及「价格新高但热度不创新高」的背离。
2. **条件化**：只在 MA200 上方启用情绪减仓，避免牛市初期误伤。
3. **更细的情绪粒度**：涨停/连板/炸板（需开通接口权限，或用全市场日线自算）。
4. **LLM 文本**只做前向增量，不参与历史回测。

### 3.3 修正口径：非 HS300 指标 + 动态仓位（2026-11-03）

按「信号只用全市场情绪、标的仍是 510300」重跑：

- 复合热度只用：沪深A股成交额、沪深A股换手率、两融余额、融资买入占比、北向净流入；
- 沪深300 自身 PE/换手率只作单指标参考，**不进信号**；
- 动态仓位：热度 ≤50 满仓，50→100 线性降至 20%；分档仓位保留作对照。

**两融余额最突出**：5.81% 年化、-24.16% 回撤、Calmar 0.24、平均仓位 51%；同样本买入持有是 6.74% / -45.45% / 0.15。回撤改善 46.8%，CAGR 只低 0.93pct，按预注册标准通过。

- **参数平台较宽**：动态起点 30–50、最低仓位 0–0.3 时，CAGR 5.3–6.1%、回撤 -19%~-25%、Calmar 0.24–0.28，不是单点运气。
- **分段**：2013–2019 策略 8.67% vs 基准 12.33%，回撤 -24.2% vs -45.5%；2020–2026 策略 3.11% vs 基准 1.63%，回撤 -15.6% vs -42.2%。后段收益与回撤都更好。
- **为什么之前是 4.59%**：那是分档规则（80/50/20），平均仓位 66.7%；同样本基准 CAGR 6.74%，分档 4.59%，等于用 2.15pct 年化换 15pct 回撤。动态仓位把平均仓位降到 51%，但降仓更平滑，CAGR 5.81%、回撤 -24.2%，才过线。
- **别急着用**：8 指标 × 2 规则 = 16 次检验，4 个通过存在多重检验；两融分位 >80 的时间占 55%，本质是「杠杆高就少拿」，更像 beta 管理而非精确择时。
- **下一步**：固定 start=50、floor=0.2，加 5% 死区，做 12 个月前向纸面跟踪；不再调参。若前向仍成立，再考虑作为 510300 的风险预算规则。

结论修正：**「全盘组合」不成立，但「两融单指标 + 动态仓位」通过初筛**。之前「情绪基本不成立」的说法过强，准确表述是「等权复合不成立，单指标里有两融这类有效候选」。

**结论**

- 纯 BS 下 4 条通过：PE 反转、沪深300换手率反转、北向趋势、开户趋势。
- 但 PE/换手率是 HS300 自身指标；只看「非 HS300」的全市场指标，只有北向/开户在较短样本上通过，且收益不高。
- **两融纯 BS 不成立**：反转规则平均仓位 8.5%、年化 4.18%，Calmar 0.31 但比基准低 2.56pct；趋势规则仓位 89%、回撤 -45.45%，等于没防守。两融的价值只在**部分仓位**（3.3 节动态）里出现。
- 复合 BS 反转：回撤 -14%、Calmar 0.34，但平均仓位 11%、年化 4.70%，同样因收益差未过线。高 Calmar 来自长期空仓，不是择时能力。
- 所以「只控制 BS」比「动态仓位」更苛刻：二元切换要么长期空仓放弃收益，要么长期满仓放弃防守。若一定要 BS，候选是 PE/换手率反转；若只用全市场情绪，两融不适合做二元。

## 四、择时验证设计

### 4.1 评价指标

| 维度 | 指标 | 说明 |
|---|---|---|
| 收益 | 年化收益、累计收益、超额（几何） | 超额分别对 510300、000300 计算 |
| 风险 | 年化波动、最大回撤、回撤修复天数、下行波动 | 回撤是主判定指标 |
| 风险调整 | 夏普、卡玛、Sortino | 卡玛用于「收益/回撤」权衡 |
| 交易 | 信号次数/年、平均持有天数、换手率、成本后收益 | 单边成本建议万 2.5 起，做敏感性 |
| 稳定性 | 分年度/分市况、滚动 3 年超额、参数邻域 | 牛/熊/震荡分开看 |
| 显著性 | block bootstrap、随机同频率切换分布、deflated Sharpe | 防参数搜索过拟合 |

### 4.2 预注册判定标准（防事后拟合）

- **主判定**：最大回撤改善 ≥30%，且年化收益不低于基准 -1pct；或卡玛比率提升 ≥0.3。
- **次判定**：样本外（最后 3 年）表现不低于样本内的 70%；阈值/窗口邻域内结论方向一致。
- **不通过也写结论**，不允许换区间、换阈值直到通过。

### 4.3 分阶段执行

1. **P0 数据管道**：510300/000300 历史、复权口径、现金腿、信号落库、T+1 执行、成本假设。
2. **P1 单指标事件研究**：用可回补指标（成交额分位、两融、新基金、开户、百度热搜）逐个做事件研究。
3. **P2 复合信号**：分位打分 + 五档仓位，walk-forward 与参数敏感性。
4. **P3 LLM 前向跟踪**：冻结规则，纸面跟踪，做增量检验。
5. **P4 完整报告**。

## 五、LLM / 文本指标的验证方式

### 5.1 先说结论

- 历史文本大多拿不到；**更关键的是，即使拿到，LLM 回填也有后视偏差**——模型训练语料包含后续结果与市场共识，用今天的模型给 2020 年的文本打分，等于让「知道答案的人」做历史判断题。
- 因此 LLM 指标不应做历史回填验证，只能做「当期可信性 + 前向有效性」。
- 可长历史验证的是**结构性情绪指标**；LLM 的角色是「更早/更细地识别同一情绪状态」，验证它是否有增量。

### 5.2 三类验证

| 类型 | 回答的问题 | 方法 | 建议通过线 |
|---|---|---|---|
| 可信性 | 打分稳定、可复现吗 | 重测信度、跨模型/提示词一致性、人工标注 | α/κ ≥0.6（探索）、≥0.8（正式）；与人工一致率 ≥75% |
| 构造效度 | 测的是不是情绪 | 与结构性指标同期相关 | \|r\| 0.2–0.6；>0.8 说明冗余，<0.1 存疑 |
| 有效性 | 有没有择时增量 | 前向纸面跟踪、事件研究、消融 | 见 5.4 |

### 5.3 六种可执行方法（没有历史数据也能做）

1. **重测信度**：同一批 300 条文本，温度 0 重复 3 次；再换 2 个模型、2 版提示词，算 ICC 或 Krippendorff's α。
2. **人工标注校准**：分层抽 300 条（新闻/股吧/研报/官媒各 75），双人标注，算 Cohen's κ、混淆矩阵、校准曲线。
3. **构造效度**：LLM 情绪分与同期成交额分位、两融买入占比、涨停家数做相关；相关性太低说明测的是噪声，太高说明只是重复已有指标。
4. **代理变量映射**：当期同时记录 LLM 分与可长历史的代理（如「散户关注度」= 百度热搜 + 换手率分位）；先用代理的长历史验证择时，再把 LLM 相对代理的残差作为增量信号。
5. **前向纸面跟踪**：冻结规则，从上线日起每日/每周落库；记录信号后 5/20/60 日超额与最大回撤；样本至少 30 个事件或 12 个月；用事件级 bootstrap，不用日频 t 检验。
6. **消融与压力测试**：复合分含/不含 LLM 层对比；把 LLM 层替换为随机噪声、滞后 5 日、打乱顺序。若结论不变，说明该层没有增量。

### 5.4 最小实验设计（建议直接照做）

- **文本池**：每日抓取固定数量（新闻标题、股吧热帖、研报摘要），按来源分层抽样，落库保存原文与抓取时间。
- **标注**：300 条双人标注，先算人工一致性；人工都不一致的样本剔除。
- **打分**：固定提示词与模型版本，温度 0；每周对同一批样本重复 3 次做信度检查。
- **跟踪**：每周记录复合分，以及 510300 未来 5/20/60 日收益、最大回撤。
- **统计**：事件级 bootstrap 或置换检验；预先写死通过标准。
- **通过条件**：LLM 层相对「不含 LLM 的复合分」有正增量（超额或回撤改善），且消融后结论反转。

### 5.5 不能做的事

- 用今天的模型给历史文本打分，当作历史信号。
- 用不足 1 年的样本做收益归因。
- 用「逻辑上说得通」「叙事完整」替代统计证据。
