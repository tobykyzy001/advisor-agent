## 0. 结论速览（agent 直接取用）

| 问题 | 一句话答案 |
|------|-----------|
| 景气投资如何赚钱？ | 赚「行业盈利周期上行 + 市场估值扩张」的双重收益，核心机制是**戴维斯双击**（股价 = EPS × PE，两者同向上行）；超额收益集中在**景气拐点**处，靠抢先捕捉「盈利预期上修」赚钱。 |
| 景气投资是不是价值投资？ | **不是**。它在进场逻辑（买成长/景气向上 vs 买便宜/安全边际）、离场逻辑（景气见顶 vs 均值回归）、风险画像（戴维斯双杀 vs 价值陷阱）上都不同，本质是「以盈利基本面为动量的成长投资」。 |

## 1. 景气投资是什么

「景气投资」（景气度投资 / 景气成长动能投资）是一种**围绕「行业/公司盈利景气度的周期位置」做配置**的投资方式：

- 偏**自上而下定方向**（宏观经济周期 → 行业景气）叠加**自下而上验证**（业绩预告、财报、分析师预期）。
- 核心是买「**盈利增速正在向上、且该向上趋势尚未被市场充分定价**」的板块。
- 中文策略界的经验法则：**「景气度高低决定相对收益高低」**——景气向上的板块相对收益最优。

---

## 2. 景气投资是如何赚钱的

赚钱的根本来源是**业绩增长被真实兑现到利润表**（营收、毛利率、净利率、现金流逐季确认），而不是靠讲故事。其放大机制的经典表述是**戴维斯双击**：

```
股价 = 每股盈利(EPS) × 市盈率(PE)
盈利上行(分子↑) × 估值扩张(分母↑) = 双击，涨幅远大于单纯盈利增长
```

- **双击（Davis Double Play）**：盈利与估值同时向上，产生相乘而非相加的涨幅。景气投资正是在「景气度向上」的阶段刻意捕捉双击。
- **双杀（Davis Double Kill，反向）**：盈利下滑 + 估值收缩同时发生，跌幅被放大——这是景气见顶后的最大风险。

**关键收敛点：赚钱集中在「拐点」**。盈利由降转升（增速"二阶导"转正、分析师一致预期开始**逐季上修**）的阶段，往往正是「盈利 + 估值」同时向上、弹性最大的窗口。

**进出场纪律**：
- **进场**：景气上行早期拐点买入——盈利刚从底部起来、估值仍低、市场尚未充分反映，吃主升段。
- **离场**：在景气见顶前或见顶初期卖出，不赚最后一个铜板。纪律是「在**景气度最高、情绪最热、估值最贵、盈利预期最满**时逐步兑现」，此后大概率进入戴维斯双杀。

## 3. 景气投资是不是价值投资

**结论：不是价值投资，两者在四个维度上都不同，但可互补。**

| 维度 | 价值投资 Value | 景气投资 Prosperity/Growth-Momentum |
|------|---------------|-------------------------------------|
| 进场逻辑 | 便宜 + 安全边际：价格低于内在价值（低 PE/PB、DCF 便宜） | 成长 + 景气向上：买「盈利增速向上」的趋势，可能并不便宜，甚至"贵得有理" |
| 持有逻辑 | 长持到价格回归价值，容忍短期波动 | 顺着盈利上行周期持有，持有期与景气周期长度挂钩，景气转弱即减仓 |
| 离场逻辑 | 均值回归：价格回归内在价值后卖出（贵了就卖） | 景气见顶回落：盈利增速拐头、预期下修时卖出（不纠结绝对估值） |
| 风险画像 | 价值陷阱：便宜但基本面持续恶化，越跌越买反被套 | 戴维斯双杀/高位接盘：景气见顶后盈利与估值双杀，或追高买在情绪顶部 |

**定位**：景气投资更接近**成长投资（growth）**，并叠加了**动量/趋势（momentum）**成分——但它是「**基本面动量**」（盈利动量 + 盈利预期上修），而非纯价格动量。

**A股实践背景（业内通行归因，正式引用前请回溯券商原研报核验）**：A股对「盈利增速（景气度）」的定价权显著高于对「静态估值」的定价权。代表框架：
- **天风证券（刘晨明团队）**：淡化指数、重视景气度，核心结论是决定 A股超额收益的首要因子是**景气度（行业盈利增速）而非估值**。
- **长江证券（包承超）**：行业比较概括为「**景气度决定相对收益，估值决定回撤/波动**」。
- **广发证券（戴康团队）**：以「流动性—盈利」「汇率—风险偏好」框架做行业比较，用「景气度 + 估值分位」选行业。
- **中金公司（王汉锋团队）**：重视盈利增速、ROE 与景气变化作为行业配置的锚。

## 4. 景气投资如何估值

**为什么静态估值会失效**：周期/景气型公司盈利在周期内大幅波动，静态 PE 在盈利高点天然显得很低、在盈利低点天然显得很高；DCF 在短期高增长阶段自由现金流为负/不稳、长期假设高度不确定，极易在周期股上给出「低点买贵、高点买便宜」的错判。因此**不能用孤立、静态的 PE/PB/DCF 下结论**。

### 4.1 常用估值方法（按景气适配度）

| 方法 | 用途 | 说明 |
|------|------|------|
| **前瞻/动态 PE**（forward PE） | 周期/成长通用 | 用「下一期或未来 12 个月预测盈利」作分母，替代历史盈利，规避用低迷/见顶的静态盈利误判。 |
| **周期中枢盈利 / 调整估值** | 周期股核心 | 取一个完整景气周期的「中枢/正常年份盈利」估值，平滑高低点。与 **Shiller CAPE**（过去 10 年平均盈利归一化）思路一致。 |
| **PEG（PE/盈利增速）** | 成长标判断"贵不贵" | 增速高可给高 PE，PEG≈1 以内相对合理，PEG 过高（如增速 20% 却给 60 倍）提示透支。 |
| **逆向 DCF / 隐含增长率** | 景气股市值"温度计" | 反推「当前股价隐含了多高的未来盈利复合增速」，与自己对行业的判断对比：隐含增速远超合理 → 泡沫化；低于行业可达水平 → 可能有空间。 |
| **相对估值分位**（PE 分位） | 判断过热/降温 | 将当前（前瞻/动态）PE 放在该行业自身历史分布中看分位。分位过高 **叠加** 景气见顶 = 高危。 |
| **EV/EBITDA** | 重资产周期制造 | 规避折旧/资本结构导致的盈利失真，比 PE 更反映经营。 |
| **PS（市销率）** | 早期未盈利高景气成长 | 利润尚未释放（未盈利或不稳定）时用收入而非利润给估值。 |

> 核心心法：**周期股永远用「中枢/前瞻盈利」估值，绝不用「顶点盈利 × 顶点倍数」，也不要在静态 PE 最低（恰好是盈利顶点）时当作"便宜"。**

### 4.2 景气度（领先）指标体系——决定估值的"周期位置"

估值必须放在周期位置上判断，输入指标：
- 微观：**订单、产能利用率、库存周期（补库/去库）、产品价格（涨价是领先/同步信号）、产销率**。
- 中观/商品：商品现货与期货价格、行业价格指数。
- 宏观：**PPI**（工业品价格，与周期股盈利高度相关）、**PMI**（新订单/生产分项）、**社融与 M2**（信用扩张领先需求与企业盈利）。
- 周期定位：**美林投资时钟**（按「增长 × 通胀」分 复苏→过热→滞胀→衰退 四象限，指导超配行业）。

### 4.3 三位一体判断（避免只看一个数）

```
景气度（周期位置 + 盈利方向） × 估值（前瞻/中枢 + 分位） × 交易结构（拥挤度/机构仓位）
```
三个维度共振向上才是安全的高质量买点；仅"景气好"或仅"便宜"都容易踩坑（见第 6 节）。

## 5. 景气周期判断框架（自上而下 → 自下而上）

1. **自上而下——宏观周期定位（美林时钟）**：用「增长 + 通胀」划分经济象限，识别处于景气向上象限的大行业，决定风格/顺周期的 β 方向。
2. **中观——行业景气度**：用**行业/板块整体盈利增速（同比、环比）**与**景气扩散指数**（行业内经营向好/盈利上修的公司占比）判断行业是否处于景气上行通道，以及上行是「广度扩散」还是「少数龙头独强」。
3. **自下而上——业绩确认**：用**业绩预告、中报、年报**验证「预期中的景气 → 报表里的景气」，过滤伪景气。

**核心领先指标——盈利增速的"二阶导"（盈利预期上修/下修）**：
- 市场真正敏感的不是「当前增速多高」，而是「增速的方向/变化率」。
- **分析师一致预期的上修/下修**是最灵敏的拐点信号：一致预期开始**逐季上调** → 对应景气反转初段，是最值得买入的窗口；一致预期**密集下修** → 即便当期增速仍高，也应警惕景气见顶回落。
- A股经验上，「盈利二阶导转正（预期上修）」对超额收益的指示意义常强于「盈利一阶导绝对值」。

**实操闭环**：宏观象限 → 锁定景气向上大方向 → 中观景气扩散确认行业 → 业绩预告/财报 + 预期上修做最终确认 → 景气拐头（预期下修）即退出。

## 6. 常见陷阱（务必警惕）

1. **高位买入景气见顶**：在景气最高点、情绪最热、估值最贵时追入，随后盈利与估值双杀。最大亏损来源——「买在利润率最高、预期最满点」。
2. **景气度与股价脱钩**：景气向好但股价已不涨（预期已充分/透支、拥挤度高、机构抱团松动、流动性收缩、估值分位过高提前见顶）。此时「基本面好」不再是上涨理由，须靠「预期差 + 估值 + 交易结构」综合判断，不能无脑看景气。
3. **周期股 PE 悖论 / 周期股价值陷阱**（彼得·林奇《战胜华尔街》经典告诫）：
   - 周期股在**盈利顶点 PE 最低、PB 最高，反而是卖出信号**；在**盈利谷底 PE 最高（悲观、盈利极低），往往是底部买入区**。机械地"买低 PE 卖高 PE"在周期股上必然做反。
   - 更糟的是「按低 PE 买周期股」常落入价值陷阱——便宜是因为盈利（及整个行业）正在快速恶化，越买越跌。
   - 对策即 4.1 节：中枢盈利 + 前瞻盈利 + 相对分位，而非静态 PE。
4. **宏观景气与个股盈利传导滞后**：宏观/行业景气向好但传导到个股报表存在时滞（价格、库存、产能爬坡）。需区分「行业 β」与「个股 α/兑现节奏」，用业绩预告与预期上修做二次确认，避免「宏观对了、股票错了」。
5. **伪景气**：一次性收益/非经常性损益/会计调节粉饰盈利。需看**扣非、现金流、毛利率稳定性、订单与应收/存货匹配度**辨别真伪。

## 7. 与现有系统的对应/落地建议

现有系统（valuation / screener / portfolio / knowledge）以**静态估值 + 质量**为主，属偏价值风格。接入景气投资视角时的扩展点：

- **valuation/relative.py**：新增「前瞻 PE（fwd_eps）」「周期中枢盈利」「行业 PE 分位」「逆向 DCF 隐含增长率」指标，作为现用 PE/PB/PEG 的补充，而非替代。
- **analysis/screener.py**：把「盈利预期上修（二阶导为正）」设为一个独立正分因子；对周期/景气型标的，把「静态低 PE」降权，改为「中枢盈利 + 前瞻 PE + 分位」打分。
- **portfolio/risk.py**：景气投资天然集中、波动大，现有「单行业 ≤30%、回撤预警」规则正好可约束景气风格的集中度风险。
- **knowledge/rules/**：景气判断规则可检索（见 `prosperity.yaml`）；券商框架、美林时钟、周期股悖论等背景知识引用本文件。

## 8. 关键概念出处速查

- 戴维斯双击/双杀：戴维斯家族（Shelby Davis、Christopher Davis），价投体系经典的「盈利 × 估值」乘积框架。
- 周期股 PE 悖论：彼得·林奇，Peter Lynch，《战胜华尔街》(Beating the Street)。
- CAPE/周期调整市盈率：Robert Shiller（及 John Campbell），用 10 年平均盈利（经通胀调整）平滑周期。
- 美林投资时钟：Merrill Lynch《The Investment Clock》(2004, Trevor Greetham 主要作者)。
- PEG：广泛归因于彼得·林奇推广（成长与市盈率挂钩）。
- 逆向 DCF/隐含增长率：业内通用的估值压力测试思路，无单一作者。
- 「景气度决定相对收益」「盈利预期二阶导」：A股策略界普遍共识，业内主要归因于天风（刘晨明）、长江（包承超）、广发（戴康）、中金（王汉锋）等团队框架。

> 核验提示：第 3 节券商框架的归属为「业内通行归因」，若用于正式研报/引用，请回溯各券商原研报核验标题与年份。
